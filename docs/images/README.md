## Рекомендации / Tips

- Формат PNG, ширина ~1600–2000 px, соотношение близко к 16:9 (кроме таблиц — там любые).
- Тёмная тема выглядит консистентно со скриншотами интерфейса.
- Скрывайте личные пути/данные, если они не нужны в кадре.
- После добавления файлов ничего в README менять не нужно — ссылки уже настроены.
